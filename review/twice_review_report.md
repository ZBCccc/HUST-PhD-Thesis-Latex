# 5. 第二轮审阅结论

## 5.1 第一章是否准确支撑第二、三章？

**部分准确，存在多处偏差。** 主要问题：(1) 创新点一安全性质列举不完整；(2) 泄露配置声明过强；(3) "确定性判定"表述与 RBF 语义保留矛盾；(4) "三类安全目标"框架无法映射到正文定义体系；(5) 两阶段划分与实际章节内容不对应。这些问题均可通过局部修订解决，不需要重写绪论。

## 5.2 第二章与第三章是否构成两个可区分的创新点？

**是。** 两个创新点的技术边界清晰且互补：
- 第二章：给定正确地址 → 保证位值真实性（绑定健全性）
- 第三章：保证地址本身的正确性（地址绑定健全性）
- 组合后：位值真实性 + 地址正确性 = 完整的判定可验证性（在候选枚举完整性前提下）

两章不是同一思路的变体，而是解决同一问题的两个正交维度。依赖关系明确：Ch2 的绑定健全性以地址归属正确为前提，Ch3 闭合该前提。

## 5.3 前三章目前最大的 5 个剩余风险

1. **声明-兑现风险**：绪论多处 overclaim（C3, C5, M6, M7），审稿人会逐条对照
