\cabstract{
可搜索加密技术允许在密文状态下进行检索，为云端数据的隐私保护与可用性平衡提供了有效解决方案。在多用户多关键词对称可搜索加密场景中，一旦云服务器偏离协议规定并返回不完整或虚假的搜索结果，授权用户往往缺乏有效的应对与验证手段。现有可验证方案大多将验证范围局限于最终结果集的正确性，对搜索流程内部关键步骤是否严格依协议执行缺乏有效的检验能力。

针对上述局限性，本文以多用户动态合取查询的对称可搜索加密方案为基础框架，围绕资格检验的位值真实性与地址归属正确性两个核心维度分别设计了轻量级的可验证机制。首先，由于现有方案采用概率数据结构进行资格检验且无法提供密码学证据，本文提出了基于默克尔哈希树的可验证资格检验机制。该机制赋予客户端对服务器返回的判定位值进行独立验证的能力，本文同时给出了该机制安全性的形式化证明。其次，在不经意伪随机函数盲化架构下客户端无法直接观测物理寻址过程。为解决这一隐患，本文进一步提出了基于默克尔选择性开封的地址绑定验证机制。该设计确保客户端能够严格验证服务器所使用的采样地址是否属于经授权方认证的合法集合，并在标准密码学假设下完成了地址绑定健全性的形式化证明。

本文基于上述两类机制构建了完整的多用户多关键词可搜索加密方案，并在多个公开数据集与多种参数配置下进行了系统的性能评估实验。实验结果表明，相较于基础方案，引入这两类可验证机制后客户端与服务器的搜索时间开销增幅均处于可控的极低水平，且客户端存储开销增量几乎可忽略不计。整体方案在不同数据集与查询场景下均展现出优异的性能表现与高度的实用价值。
}

\eabstract{
Searchable encryption technology allows retrieval in ciphertext state, which provides an effective solution for the balance between privacy protection and availability of cloud data. In the multi-user multi-keyword symmetric searchable encryption scenario, authorized users lack effective detection methods when the cloud server deviates from the protocol execution and returns incomplete or incorrect search results. Most of the existing verifiable schemes limit the verification scope to the correctness of the final result set, and there is no effective test on whether the key steps within the search process are executed according to the protocol. 
 
In view of the above problems, this paper takes a class of symmetric searchable encryption schemes supporting multi-user dynamic conjunctive queries as the basic framework, and designs corresponding lightweight verifiable mechanisms around the two dimensions of bit value authenticity and address attribution correctness. Firstly, aiming at the problem that the existing schemes use probabilistic data structure for qualification verification and cannot provide cryptographic evidence, a verifiable qualification verification mechanism based on Merkel hash tree is proposed, which enables the client to independently verify the judgment bits returned by the server, and formally prove the correctness, binding integrity, version consistency and conditional integrity of the mechanism. Secondly, aiming at the problem that the client cannot observe the physical addressing under the inadvertent pseudo-random function blinding architecture, an address binding verification mechanism based on Merkel 's selective unpacking is proposed, which enables the client to verify that the sampling address used by the server belongs to the legal set certified by the authorized party, and complete the formal proof of the integrity of the address binding under the assumption of standard cryptography.

The multi-user multi-keyword searchable encryption scheme constructed by the above mechanism performs performance evaluation experiments under multiple public data sets and various parameter configurations. The experimental results show that compared with the basic scheme, the two mechanisms introduce verifiability, while the search time overhead of the client and the server is limited, the client storage increment is negligible, and the acceptable performance is maintained in different data sets and query scenarios.
}
